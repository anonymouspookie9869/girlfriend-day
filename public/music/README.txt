Place your music / song files in this directory:
- /public/music/music1.mp3
- /public/music/music2.mp3
- /public/music/music3.mp3
- /public/music/music4.mp3

Supported format: MP3 (.mp3).
The application is configured to fetch these songs directly from /music/music1.mp3, /music/music2.mp3, etc.
If a local MP3 file is not uploaded yet, a graceful ambient acoustic stream automatically plays as a fallback so the experience is seamless!
