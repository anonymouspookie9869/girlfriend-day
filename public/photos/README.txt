Place your photo files in this directory:
- /public/photos/image1.jpeg
- /public/photos/image2.jpeg
- /public/photos/image3.jpeg
- /public/photos/image4.jpeg
- /public/photos/image5.jpeg

Supported format: JPEG (.jpeg or .jpg).
The application is configured to fetch these images directly from /photos/image1.jpeg, /photos/image2.jpeg, etc.
If a local JPEG file is not uploaded yet, a beautiful Unsplash photograph will automatically display as a fallback so the gallery looks perfect!
